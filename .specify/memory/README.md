## Philosophy

- **Manual validation only** - No automated testing or success criteria
- **Requirements emerge from failures** - New requirements brought forward only when something breaks
- **No upfront success metrics** - Success determined by infrastructure functioning as needed in practice
- **AWS-first validation** - Infrastructure validated directly on AWS
